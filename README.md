# 풍미예찬클럽 현미흑초 테이스팅 (모바일 파일럿)

인양양초장 × 푸딩클럽 협업 제안용 컨셉 목업입니다.

- `index.html`: 테이스팅 휠, PTCI 맛취향 문항, 풍미 리포트, 페어링 추천까지 한 파일로 동작하는 모바일 웹 페이지 (데이터와 이미지 내장)
- `data.json`: 휠 단어, 시료 3종(3·5·8년 숙성), PTCI 16개 코드별 추천 데이터

시료 구성, 참여자 표현 수, 바디감·질감·여운 점수, 추천과 매치율은 모두 예시이며 실제 구성은 협의를 통해 결정합니다. 이 페이지는 응답을 저장하지 않습니다.
